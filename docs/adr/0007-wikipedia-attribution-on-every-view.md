# Every Wikipedia Article view carries CC BY-SA attribution

An Article's Location line always reads `CC BY-SA 4.0 · <canonical URL> · Reformatted to markdown`. This is a licence requirement, not decoration, so don't trim it. CC BY-SA 4.0 needs attribution (a link to the article is enough), a notice naming the licence, and an indication that the content was modified, which noggin's HTML→markdown conversion does. We looked at relying on a "purely local, personal use" exemption and rejected it. The licence's definition of sharing includes public display, and comparable readers such as Kiwix and Wikiwand attribute even single-user renders that are never saved.
